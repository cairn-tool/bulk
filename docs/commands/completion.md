# `completion`

## Synopsis

```text
bulk completion <shell>
```

Prints a shell completion script for `bash`, `zsh`, `fish`, or `powershell`, generated from the
same command walk `describe` uses — so every plugin, sub-command and option is completable, and
option values with a fixed vocabulary (`--mode`, `--order`, `--format`) complete to it.

```bash
# zsh
bulk completion zsh > "${fpath[1]}/_bulk"
# bash
bulk completion bash > ~/.local/share/bash-completion/completions/bulk
# fish
bulk completion fish > ~/.config/fish/completions/bulk.fish
```

Regenerate after upgrading; the script names the version it was generated by.

## Arguments

| Argument | Required | Description                             |
| -------- | -------- | --------------------------------------- |
| `shell`  | Yes      | `bash`, `zsh`, `fish`, or `powershell`. |

## Exit codes

| Code | Meaning         |
| ---- | --------------- |
| `0`  | Script written. |
| `1`  | Unknown shell.  |
