# NRC ADAMS — access research

What was established, by making the requests rather than reading about them, before the `nrc-adams` plugin was written. Ported from the research note `access-notes.md` in the original notes; every request below was actually made.

Probed 2026-09-13 for `bulk nrc-adams fetch`. ADAMS is the NRC's document
library; its public face is now **ADAMS Public Search (APS)** at
`adams-search.nrc.gov`, an Angular app over a JSON API on the same host.

**Two findings overturn the earlier record.** (1) `adams.nrc.gov` — the
host of the old WBA search and its documented "ADAMS Public API" — no
longer resolves in DNS; the search moved to `adams-search.nrc.gov`
(`adamswebsearch2.nrc.gov` still resolves but serves nothing useful).
(2) `www.nrc.gov/docs/…pdf`, recorded as Akamai-denied, denies only the
browser user agent sent from curl; curl's own UA is served the PDF.

| Question          | Answer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Catalogue         | **`POST https://adams-search.nrc.gov/api/search`**, JSON, anonymous: `{"q": "", "filters": [...], "anyFilters": [], "legacyLibFilter": true, "mainLibFilter": true, "content": false, "size": 1000, "skip": 0}` → `{"count", "results": [{"document": {...}}], "facets"}`. A text filter is `{"field": "<cogSearchKey>", "value": "<text>", "operator": "equals"}`; a date filter `{"field": "DateAdded", "value": "(DateAdded ge '2026-09-01' and DateAdded le '2026-09-02')"}` (`DocumentDate` likewise). `q` takes free text and Lucene field syntax (`DocumentType:"Inspection Report"`) |
| Traps             | **`q` must be `""` when filters are given** — with `q: "*"` every text filter matches nothing (the accession-number filter alone still works, which hid this at first). `sortDirection` → 500; leave sorting out. `size` below 100 returns 100; 1,000 works; `skip` pages. `filters` and `anyFilters` are required even when empty (400 otherwise)                                                                                                                                                                                                                                           |
| Record            | `AccessionNumber`, `DocumentTitle`, `DocumentDate`, `DateAdded`, `DocumentType[]`, `DocketNumber[]`, `AuthorName[]`, `AuthorAffiliation[]`, `DocumentReportNumber[]`, `LicenseNumber[]`, `PackagesFiledIn[]`, `DocumentsFiledInPackage[]`, `IsPackage`, `IsLegacy`, **`Url`** (`https://www.nrc.gov/docs/ML1112/ML11126A118.pdf`; a package's is `.html`), `DocumentSize`, `EstimatedPageCount`. `GET api/metadata` lists the 29 searchable keys; `GET api/appsetting` gives `LastAdamsUpdate`                                                                                               |
| File              | The record's `Url`; served with curl's UA, 403 to the browser UA. `DocumentSize` is **not** the served byte count (162,334 listed, 163,978 served) — verify by magic, not size                                                                                                                                                                                                                                                                                                                                                                                                               |
| Packages          | `IsPackage: Yes` records have no file; their members are found with `{"field": "PackagesFiledIn", "value": "<package ML>", "operator": "equals"}`                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Mutability        | Documents are added daily (`DateAdded`); accession numbers are stable                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Other hosts       | `adams-api-developer.nrc.gov` and `adams-api.nrc.gov` (Azure API Management) exist — a developer API, presumably keyed; not probed further. `adamspublic.nrc.gov/navigator/` is the legacy folder navigator                                                                                                                                                                                                                                                                                                                                                                                  |
| The archive holds | 29 `ML…` files under `Agencies/NRC/` (US-EPR, ESBWR, NuScale, NUREG folders)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
