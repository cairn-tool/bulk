# ITU-T Recommendations — access research

What was established, by making the requests rather than reading about them, before the `itu-t` plugin was written. Ported from the research note `access-notes.md` in the original notes; every request below was actually made.

Both ITU sectors were researched in session
[20260913-001](../../guide/fetching.md) (2026-09-13): ITU-T
1,129 of 1,260 texts fetched, ITU-R 94 of 94. This note records what that
session established and what `bulk itu-t fetch` and `itu-r` rely on.

## ITU-T

| Question                       | Answer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Catalogue                      | **`https://www.itu.int/mws/api/recommendations/searchRecs?query=&series=<X>&main_edition_flag=false&approved_from=<date>&approved_to=<date>&rows=5000&page=1`** — the JSON behind the MyWorkspace site, unauthenticated. `Data[]` rows carry `idrec`, `rec_name` (`D.1040 (2020) Amd. 1 (07/2024)`), `title`, `approval_date`, `status`, `dms_link` (`https://www.itu.int/rec/T-REC-D.1040-202407-I!Amd1`). `main_edition_flag=false` includes amendments, corrigenda, errata and supplements. An `approved_to` year past about 2030 is a 500 |
| File                           | `https://www.itu.int/rec/dologin_pub.asp?lang=e&id=<dms id>!!PDF-E&type=items`; when the id already carries a `!` (a component), a single `!` before `PDF-E`. Software/data packages: `<id>!!SOFT-ZST-E` (zip)                                                                                                                                                                                                                                                                                                                                |
| Failure modes                  | Prepublished (`-P`) texts and in-force ISO/IEC common texts are TIES-only: the endpoint returns an HTML "ITU Publications" page with HTTP 200 — the magic check catches it. A component of a since-superseded edition can be "Document Not Found". Texts approved in the last two months are often "To be published"                                                                                                                                                                                                                          |
| Mutability                     | Editions are immutable; new editions and components are added; a prepublished text becomes public months after approval — so a re-pull with the same `--approved-from` picks up what was TIES-gated before                                                                                                                                                                                                                                                                                                                                    |
| Pacing                         | 5 s between catalogue calls in the session; files at 2 s                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Legacy routes that do not work | The per-series RSS feeds stop in 2019; `rec/new.asp` is empty; the old `search.aspx` postback form returns main editions only                                                                                                                                                                                                                                                                                                                                                                                                                 |
