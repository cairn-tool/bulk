# NOAA Institutional Repository — access research

What was established, by making the requests rather than reading about them, before the `noaa-ir` plugin was written. Ported from the research note `access-notes.md` in the original notes; every request below was actually made.

Probed 2026-09-13 for `bulk noaa-ir fetch`. The repository documents two
public services in
[github.com/NOAA-Central-Library-NCL/NOAA_IR](https://github.com/NOAA-Central-Library-NCL/NOAA_IR)
(a JSON API and OAI-PMH); the README was read from the repository's
`master` branch.

**The finding that overturns the earlier record.** Session 20260913
(engineering-and-science title determination) recorded the NOAA IR as
"Akamai 403, blocked to scripts". It is not: Akamai denies the _browser_
user agent sent from curl (`Mozilla/5.0 (Macintosh…) Chrome/124`) and a
made-up one (`bulk/1.0`), and serves **curl's own** (`curl/8.7.1`),
`python-requests/2.32`, or no `-A` at all. Every request the command
makes carries `curl/<version>`.

| Question          | Answer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Catalogue         | `https://repository.library.noaa.gov/fedora/export/view/collection/noaa:<pid>?rows=<n>` — one call per collection (`rows=1` first for `response.numFound`, then `rows=numFound`); `from`/`until` (`YYYY-MM-DDTHH:MM:SSZ`) filter by date added. Collection PIDs: NEPA 1, CRCP 3, OER 4, NMFS 5, NWS 6 (5,660 items), OAR 7, NOS 8, NESDIS 9, Sea Grant 11, Education 12 (287), General 10031, International Agreements 11879, OMAO 16402, IEA 22022, Cooperative Institutes 23649, CSCs 24914, WRFIA 23702, DWH 44280. `…/fedora/export/download` is the whole repository as one JSON |
| Record            | Solr-style docs: `PID` (`noaa:24650`), `mods.title`, `mods.type_of_resource`, `mods.ss_publishyear`, `mods.sm_localcorpname`, `mods.sm_digital_object_identifier`, `rdf.isMemberOf` (items are shared across collections), and for the attached file `DS1.label_txt_en`, `DS1.mimetype_txt_en`, **`DS1.filesize_tl`**, **`DS1.checksumsha256_txt_en`**                                                                                                                                                                                                                                |
| File              | `https://repository.library.noaa.gov/view/noaa/<n>/noaa_<n>_DS1.pdf` — plain, `application/pdf`; the item page `view/noaa/<n>` links the same                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Failure modes     | Browser UA → 403 `Access Denied`. `Accept: application/json` on the export URL → **406** (it serves `text/plain`); send `*/*`. A record without `DS1.*` has no file                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Verification      | Byte count and sha256 from the record — the command checks both                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| OAI-PMH           | `…/fedora/oai?verb=Identify                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | ListRecords | GetRecord`, `oai_dc` only; not used by the command |
| `robots.txt`      | Not fetched with the plain UA; the API is documented as public, "No API key or authentication required"                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| The archive holds | 127 `noaa_<n>` files and the NOAA technical memoranda under `Agencies/NOAA/`, filed by centre in the engineering plan                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
