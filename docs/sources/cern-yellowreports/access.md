# CERN Yellow Reports — access research

What was established, by making the requests rather than reading about them, before the `cern-yellowreports` plugin was written. Ported from the research note `access-notes.md` in the original notes; every request below was actually made. The CDS half of the same note is on [cern-cds](../cern-cds/access.md).

## Yellow Reports — e-publishing.cern.ch (open, no challenge)

The CERN Yellow Report series (`CERN-yyyy-nnn` monographs and school
proceedings) is published on an Open Journal Systems instance at
`e-publishing.cern.ch/index.php/CYR`, which has **no bot challenge**.
`bulk cern-yellowreports fetch` uses it.

| Question             | Answer                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Catalogue            | `…/CYR/oai?verb=ListRecords&metadataPrefix=oai_dc`, 100 records a page with resumption tokens (169 articles as of 2026-09-14). Each `oai_dc` record: `dc:title`, `dc:creator`, `dc:date`, `dc:identifier` (article URL + article DOI `10.5170/CERN-2015-001.1`), `dc:relation` (the galley view URL `…/article/view/75/33`), `dc:source` (ISSN + the issue DOI `10.5170/CERN-2015-001` = the report number), `dc:format` |
| File                 | The galley download `…/CYR/article/download/<article>/<galley>` (the `article/view/<a>/<g>` in `dc:relation` with `view`→`download`); `citation_pdf_url` on the article page confirms it. Plain `application/pdf`                                                                                                                                                                                                        |
| Failure modes        | None met; open OJS                                                                                                                                                                                                                                                                                                                                                                                                       |
| The oai_dc namespace | `http://www.openarchives.org/OAI/2.0/oai_dc/` (not the bare `…/oai_dc/`) — the parse must use it                                                                                                                                                                                                                                                                                                                         |

Requests: `CYR/oai?verb=Identify|ListSets|ListRecords` all 200; article
75 galley download 1.2 MB PDF; the command pulled two CERN-2015-001
articles on 2026-09-14.
